# Universal Keyboard Pro (UK Pro) — v0.2.0

Android ⇄ Windows: bidirectional keyboard, universal clipboard (text / images / files), file
transfer, remote control panel, clipboard history and multi-device — over the local network, no cloud.
All languages: text typing and copy/paste carry any Unicode script (বাংলা, English, हिन्दी, اردو, العربية, 中文, 日本語, 한국어, emoji …).

```
UKPro/
├─ docs/            PROTOCOL · ARCHITECTURE · ENVIRONMENT_REPORT · KNOWN_LIMITATIONS · BUILD · USER_GUIDE · TEST_REPORT
├─ shared/          cross-language test vectors (generated by the C# core, checked by the Kotlin core)
├─ windows/         UKPro.sln — Core (tested), Desktop (WPF tray app), Core.Tests, installer (Inno Setup), build.ps1
├─ android/         Gradle project — :core (pure Kotlin, tested), :app (IME + Compose app)
├─ interop/run.sh   Kotlin ↔ C# test over real TLS WebSockets
├─ scripts/         check-windows-env.ps1 (Phase-1 check for your laptop)
└─ .github/workflows/build.yml   builds APK + EXE + installer and runs all tests
```
