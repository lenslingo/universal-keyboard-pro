# Known platform limitations (and the closest reliable alternative)

| # | Limitation | Why | What UK Pro does instead |
|---|---|---|---|
| 1 | Remote typing on Android only works when UK Pro Keyboard is the **selected IME** and an editable field is focused. | Android only lets the active IME write into other apps (`InputConnection`). No accessibility/root tricks are used. | App shows "No text field focused" on the laptop indicator; `INPUT_FOCUS` stops Windows from sending. |
| 2 | Android background clipboard reading is blocked on Android 10+. | Platform privacy restriction. | Automatic sync while UK Pro Keyboard is the default IME (exempt); otherwise manual "Send clipboard" (notification action / app button / Share sheet). |
| 3 | Android 12+ shows "UK Pro pasted from your clipboard" / Android 13+ clipboard previews, and some ROMs auto-clear the clipboard. | Platform privacy feature. | Expected behaviour; clipboard history keeps a copy (unless sensitive). |
| 4 | Pasting **files** from the clipboard works only in Android apps that accept `content://` URIs on paste (few do). | Most Android apps only paste text/images. | File clips offer **Open / Share / Save / Transfer** actions. No universal claim is made. |
| 5 | `SendInput` cannot type into windows of **elevated** (admin) apps when UK Pro runs non-elevated (UIPI), nor into the secure desktop (UAC prompt, Ctrl+Alt+Del, lock screen). | User Interface Privilege Isolation. | Indicator shows "Target app is elevated"; optional "Run UK Pro as administrator" setting. Secure desktop is always excluded. |
| 6 | Ctrl+Alt+Del cannot be sent. | Secure Attention Sequence is reserved by Windows. | Remote panel offers Ctrl+Shift+Esc (Task Manager) and Win+L. |
| 7 | Global capture of **IME-composed** Windows text (Avro, Bijoy, Bengali Phonetic, Chinese Pinyin, Japanese, Korean, Vietnamese Telex via TSF) is not reliable from a low-level hook (it sees keys, not committed text). | TSF composition happens inside the target app's process. | Remote Text Panel on Windows sends committed text (`COMPOSITION_COMMIT`) for every language. Ordinary layouts of any language (Russian, Arabic, Hindi/Bengali InScript, Greek, Hebrew, Thai…) work directly through `ToUnicodeEx`; accent dead keys (French, Spanish, German, Portuguese…) are composed by UK Pro. |
| 12 | The UK Pro keyboard has built-in layouts for English (+ Latin accents), বাংলা, हिन्दी, اردو, العربية, Русский and Ελληνικά only. | Writing systems such as Chinese/Japanese/Korean need a full dictionary IME. | **Universal text** screen: use any keyboard installed on the phone (e.g. Gboard, 900+ languages); only committed text is sent. Clipboard sync carries any Unicode text in both directions. |
| 8 | UI Automation `IsPassword` is not exposed by every app (some games, custom-drawn or Electron fields). | App-specific accessibility support. | Privacy-first: when the focused element cannot be identified, the per-app policy applies (default: browsers & known password managers = block when unknown); user-configurable exclusion list. |
| 9 | Windows Bluetooth RFCOMM throughput is ~100–250 KB/s. | Bluetooth Classic bandwidth. | Large files require Wi-Fi; BT-only mode limits files to 25 MiB (configurable) with progress. |
| 10 | Some phone hotspots isolate clients / block mDNS. | Hotspot firmware. | QR contains all host IPs; manual IP entry fallback. |
| 11 | On Android 14+ a foreground service of type `connectedDevice` needs Bluetooth/Wi-Fi permissions granted first. | Platform rule. | Permissions are requested in onboarding before starting the service. |
